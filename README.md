## 📖 Araç Hakkında

**cin0jk Cybersecurity Automation Tool**  
Başlangıç seviyesinden ileri seviyeye kadar kullanıcılar için çok amaçlı bir güvenlik otomasyon aracıdır.  
Popüler araçları tek bir arayüzde toplar ve test süreçlerini kolaylaştırır.

## 🔥 Temel Özellikler

<div style="display: flex; flex-wrap: wrap; gap: 10px;">

- 🧩 **Hash Generator** – MD5, SHA1, SHA256 üretme  
- 🔑 **Hash Cracker** – Brute-force veya wordlist ile hash kırma  
- 🌐 **Nmap Scanner** – Ağ tarama ve servis keşfi  
- 🚪 **Gobuster** – Dizin/dosya brute-force  
- 💣 **MSFVenom** – Payload oluşturma  
- 🕵️ **Metasploit** – Exploit entegrasyonu  
- 🔄 **Reverse Shell** – Hazır payload’lar  
- ⚙️ **System Update** – Kali Linux güncelleme  
- 🕸️ **Burp Suite** – Web uygulama testi  
- 📡 **Wireshark** – Ağ trafiği analizi  
- ⚡ **Bettercap** – MITM ve gelişmiş ağ testleri  
- 🔐 **OpenVPN** – VPN bağlantısı  
- 🧪 **Hydra** – Çoklu protokol parola brute-force  
- 🔑 **SSH Key Test** – SSH anahtar test  
- 📥 **Tool Downloader** – Yaygın pentest araçlarını otomatik indir

# ⚙️ Kurulum
1️⃣ Repoyu klonlayın
git clone https://github.com/ffurares/ctf-toolkit.git

2️⃣ Proje klasörüne girin
cd ctf-toolkit

3️⃣ Python sanal ortam oluşturun
python3 -m venv myvenv

4️⃣ Sanal ortamı aktive edin
Linux / macOS
source myvenv/bin/activate
Windows
myvenv\Scripts\activate

5️⃣ Gerekli Python paketlerini yükleyin
pip install -r requirements.txt

6️⃣ Aracı çalıştırın
python3 main.py
